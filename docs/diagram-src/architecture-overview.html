Event Management on Salesforce: architecture overview PREVIEW v0.1

Salesforce-native event, class and conference management with bring-your-own payment gateway and virtual meeting provider. Optional AI layer.
1 · CHANNELS
Public websiteAny CMS (Sitecore, WordPress). Lists events from the catalog API or embeds components
Registration siteExperience Cloud (LWR). Browse, pick sessions, pay, manage booking. No login needed
Staff consoleLightning app for organizers: events, sessions, capacity, registrations, refunds
Email and calendarConfirmations, reminders, secure manage-booking links, .ics invites
AI assistant (optional)Web chat that answers questions and registers people
